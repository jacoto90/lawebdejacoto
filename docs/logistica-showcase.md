# MEIBIT — caso de estudio

La página `/proyecto-logistica/` (también `/proyecto-logistica/index.php`)
presenta el proyecto en ES/EN con `?lang=es` o `?lang=en`.

## Fuentes del contenido

- `docs/informacion proyecto logistica.txt`: manual de la plataforma,
  secuencia de diez etapas, módulos, estadísticas y configuración.
- `data/profile.php`, experiencia MEIBIT: trabajo en .NET/C#, Angular,
  SQL Server, API ASP.NET Core y sincronización local/nube.
- `images/proyecto_logistica/`: siete fotografías y capturas originales.

La presentación incluye contexto, contribución técnica, arquitectura,
recorrido interactivo, galería de interfaces, informes y valor operativo.
El recorrido es explicativo; las imágenes e informes son muestras del proyecto.

## Archivos

- `data/logistica.php`: contenido bilingüe.
- `proyecto-logistica/index.php`: marcado y selección segura de idioma.
- `assets/css/logistica.css`: diseño independiente, oscuro por defecto,
  variante clara y estilos responsive.
- `assets/js/logistica.js`: menú, etapas, pestañas, visor accesible,
  preferencia de tema y animaciones con movimiento reducido.
- `assets/images/logistica/*.webp`: versiones optimizadas de las imágenes.
- `assets/images/logistics{,-640}.webp`: nueva miniatura del portfolio.

El visor abre los JPG originales para conservar el detalle. Sin JavaScript,
las capturas siguen enlazadas y el contenido de etapas y galería permanece
visible. Los estilos y scripts antiguos compartidos no se cargan en esta página.
